# Paper-native competences

This directory contains the competences through which an AI or human editor can
work with the SSK corpus without turning a derivative into a parallel theory.

The current competence is
[`system-semantic-kernel-paper`](system-semantic-kernel-paper/SKILL.md). It owns
the Paper's argument, revision continuity, source relation, and derivation
contract at repository scale.

Later competences may emerge for:

- an AI-readable guide to SSK's internal logical relations;
- expert and philosophical explanation;
- elemental-function and value maps;
- other audience-specific forms whose repeated transformation justifies a
  distinct competence.

These functions remain reachable but are not presented as completed artifacts.
Each future competence must name the canonical manuscript revision it consumes,
preserve claim states and retained unknowns, and keep publication or external
effects with their own owners.
