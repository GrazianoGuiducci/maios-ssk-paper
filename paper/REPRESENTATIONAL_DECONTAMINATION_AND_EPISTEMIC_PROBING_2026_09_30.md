# Representational Decontamination, Epistemic Probing, and KA/FDLA

Date: 2026-09-30  
State: integrated into stable body 0.10  
Owner: system-semantic-kernel-paper + Editoriali  
Source authority: Graziano Guiducci

## Operator source

Two operator clarifications form the source pressure for this development:

> «Osservare in modo neutro fa emergere ciò che cerchiamo che non conosciamo senza cercarlo.»

> «Questo è il principio che riduce la contaminazione del campo che KA e FDLA cercano di fare.»

The Paper does not treat these sentences as an instruction to search for hidden
content. Their significance is the opposite: the receiver should not predefine
the relation that neutral observation is supposed to find.

## Relation exposed in the living Kernel

The current Kernel already carried two source-bound functions:

```text
KA:
  current representation != whole possibility field

FDLA:
  assistant-introduced substitution of source / object / meaning / intent
  -> correction inside the movement
```

The 30 September exercise added an operating consequence. A representation is
part of the observation conditions. Prose, a dependency graph, a diagram,
table, schema, pseudo-code, executable structure, example or test can expose
different relations while referring to the same selected object.

```text
same source / object relation
+ representation M_a
-> perceived relation P_a

same source / object relation
+ representation M_b
-> perceived relation P_b

P_a != P_b
```

The difference is a **representational differential**. It is informative because
the first representation may have hidden a material relation. It is also
dangerous because the second representation can manufacture its own apparent
structure.

## KA/FDLA decontamination interpretation

The representational shift is therefore not a new controller above KA/FDLA.

```text
current representation may be contaminating observability
-> KA keeps the field wider than the current form
-> representation changes without naming the required answer
-> material difference may emerge | no_change
-> FDLA tests whether that difference reconnects coherently to
   source / object / meaning / intent / consequence
-> changed comprehension or discarded probe
```

Neutral observation is compatible with an active change of medium because the
intervention changes the **conditions of observation**, not the result that must
appear.

## Claim boundary

This development is a conceptual/source formalization supported by one
living-Kernel exercise. It does not establish that:

- multiple representations are independent replications;
- agreement across representations proves truth;
- novelty in one representation proves a hidden source relation;
- every task benefits from multimodal or multi-representation treatment;
- the representation probe is a runtime module or mandatory review stage.

A probe that changes no material relation is discarded. A relation that appears
only in one form remains conditioned by that observation frame until source,
object and consequence support a stronger interpretation.
