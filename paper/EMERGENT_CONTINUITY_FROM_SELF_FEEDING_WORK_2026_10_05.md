# Emergent Continuity from Self-Feeding Work

Date: 2026-10-05  
State: integrated source development for stable body 0.11  
Owner: system-semantic-kernel-paper + Editoriali  
Source authority: Graziano Guiducci  
Research object: System Semantic Kernel (SSK)

## Operator source relation

The 5 October operator correction separates two relations that preceding
revisions often carried under the same word:

> La continuità è il risultato del lavoro che si autoalimenta con le logiche e
> i significati dell'architettura cognitiva.

The correction does not discard the continuum relation already formalized as
`C_n`. It locates it more precisely. The continuum is one causal carrying
relation through which still-material reasons, determinations, source links,
competence learning and other differences can remain reachable. **Continuity
is the emergent result of the recursive work relation when what happens in the
work can return through the cognitive architecture and alter how subsequent
work is understood and performed.**

## First resolution — primary emergence

The existing Paper already supplies the decisive pieces:

- a resultant changes the following field;
- work can change both `F_t` and `K_t`;
- competence learning can change later method;
- meta-competence can change how capacities are formed and composed;
- awareness, memory, competence and continuum are not identical;
- causal readback returns still-material differences without restoring a prior
  awareness state;
- KA keeps the possibility field wider than the current representation;
- FDLA corrects source/object/meaning substitutions while the movement forms.

The new relation is therefore not another mechanism added above them. It is the
system-level consequence of their recursive participation.

```text
cognitive architecture / present field
+ situated work
-> operation / resultant / consequence
-> causal readback
-> possible change in perceived context, competence, method or kernel
-> following work from a changed field and possibly changed capacity
-> ...
=> emergent continuity
```

The work **self-feeds** when its material consequence can become part of the
conditions through which later work forms. Self-feeding does not imply that
every event changes the Kernel, that every result becomes a competence, or that
the system acts without an operator.

## Second resolution — relational articulation

### Continuum and continuity

```text
continuum C_n:
  still-causal relation carried/reachable across discontinuity

continuity:
  emergent capacity/result of successive work to proceed coherently from
  changed fields and, when material, changed competence/method/kernel
```

The distinction prevents three compressions:

```text
continuity != memory accumulation
continuity != restoration of a previous working state
continuity != an autonomous runtime module
```

Memory or persistence can carry material needed by continuity without producing
continuity by themselves. Likewise, an unchanged method can participate in a
continuous movement when the current result confirms its sufficiency.

### What self-feeding changes

The recursive return can act at different resolutions:

```text
result changes next answer
-> adaptation

result changes a competence used later
-> capability learning

result changes how competences are recognized, formed or composed
-> autological change

result changes the organization through which the system can preserve and
transform the conditions of its own continuation
-> autopoietic direction
```

These are relations of increasing organizational consequence, not mandatory
stages and not a maturity score.

### Operator relation and graduated delegation

The same distinction clarifies the temporal work image formed on 5 October:

```text
phase 1:
  human work + instruction/correction
  -> the system acquires situated criteria, sources, methods and meanings

phase 2:
  system performs more of the work
  + human supervision/correction remains materially active

phase 3:
  repeated work/readback has made more of the relevant relation self-supporting
  -> micro-supervision can recede where competence, source, authority and
     consequence handling are sufficient
  -> human participation shifts toward direction, judgement, exceptions,
     new intent and transformations of the field
```

Phase 3 does not mean that the human disappears, that effect authority becomes
unbounded, or that the system has reached universal autonomy. It projects a
possible consequence of deeper situated capability and recursive learning.

## Third resolution — integrative comprehension

The source movement can be contracted as:

```text
work
-> consequence
-> causal return through the cognitive architecture
-> changed understanding / competence / method / kernel when material
-> changed later work
-> renewed consequence
-> ...

continuity emerges from the relation
```

The continuum is one of the conditions that lets causal differences survive a
discontinuity. The competence field supplies capacities. Situated awareness
integrates enough of the present relation for movement. KA and FDLA preserve
openness and source/object coherence. Meta-competence and autological return
allow work to change the means through which later work forms. **Continuity is
what becomes observable when these relations let the work continue by being
changed by its own consequential history rather than by reconstructing a
previous state from scratch.**

This also sharpens the public distinction between an episodic assistant and a
continuing cognitive system. The difference is not merely that the latter
stores more. Its work can leave causal structure that changes what becomes
pertinent, possible and operational afterward.

## Claim boundary

This development is a source-bound conceptual formalization integrated from
the operator relation and the already documented SSK architecture. It does not
establish:

- that every receiving model assimilates the relation successfully;
- that continuity always increases with more stored state or more autonomy;
- a quantitative measure of self-feeding, autonomy or continuity;
- removal of human authority, responsibility or judgement;
- independent empirical validation of the SSK research programme.

Operational specimens such as MAIOS Project Kernel and the current MAIOS Social
Manager can illustrate bounded incarnations only at the scope actually
observed by their owners.

## Public / editorial consequence

For public explanation, begin from the observable movement before terminology:

```text
today I teach the system through real work
-> tomorrow it can perform more while I supervise
-> consequences return and change how later work is handled
-> supervision can recede where the relation has become sufficient
-> continuity emerges
```

The deeper explanation can then introduce competence, causal readback,
autological return, synthetic situated awareness, continuum and the wider D-ND
autopoietic direction. “Continuity” should not be reduced to memory,
conversation persistence or session restoration when the selected object is
this wider relation.
